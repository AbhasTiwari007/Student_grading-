Student Grading System

A simple and interactive web-based application that allows users to calculate and analyze student grades efficiently.

🔗 Live Demo:
https://abhastiwari007.github.io/Student_grading-/

📌 Features
Input student marks easily
Automatic grade calculation
Clean and responsive user interface
Instant result display
🛠️ Tech Stack
HTML
CSS
JavaScript
🚀 How It Works
Enter student details and marks
The system processes the input
Displays grade/result instantly
📈 Purpose

This project was developed to simplify the process of grading students and to demonstrate core JavaScript logic and DOM manipulation.
